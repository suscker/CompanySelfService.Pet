# 🏢 CompanySelfService.Pet

**CompanySelfService** — это RESTful API для управления корпоративными пропусками на объекты. Система позволяет администраторам создавать сотрудников и здания, а также выдавать или отзывать пропуска. Сотрудники могут просматривать свои активные пропуска.

## 🚀 Технологический стек

*   **Платформа:** .NET 10 / ASP.NET Core Web API
*   **База данных:** PostgreSQL
*   **ORM:** Entity Framework Core (Code First)
*   **Архитектура:** CQRS (через библиотеку **MediatR**)
*   **Аутентификация:** JWT (JSON Web Tokens)
*   **Документация:** Swagger / OpenAPI

## ✨ Основной функционал

*   🔐 **Аутентификация и авторизация:** Ролевая модель (Admin, Employee), защита эндпоинтов с помощью JWT.
*   👥 **Управление пользователями (Admin):** Создание сотрудников и других администраторов.
*   🏗️ **Управление объектами (Admin):** Создание и просмотр зданий/объектов.
*   🎫 **Управление пропусками (Admin):** Выдача и отзыв (блокировка) пропусков на определенные объекты.
*   📋 **Личный кабинет (Employee):** Просмотр списка своих активных пропусков.

## 🏗️ Архитектура проекта

Проект разделен на логические слои с использованием паттерна **CQRS** (Command Query Responsibility Segregation):

*   `Controllers/` — точки входа API (принимают HTTP-запросы).
*   `Models/` — сущности базы данных (`User`, `BuildingObject`, `AccessPass`).
*   `DTOs/` — объекты для передачи данных (запросы и ответы API).
*   `Users/`, `BuildingObjects/`, `AccessPasses/` — бизнес-логика (Команды и Запросы), разделенная по доменам.
    *   `Commands/` — изменение состояния (создание, выдача).
    *   `Queries/` — получение данных (чтение).
*   `Migrations/` — миграции Entity Framework Core.
